# 설계

## 시각 기준

기존 코발트(`#1D4ED8`)·중간 파랑(`#3B5CF2`)·밝은 파랑(`#6082F7`)으로 브릭의 세 면을 구분한다. 가운데 스터드만 골드(`#EAB308`), 눈과 미소는 남색(`#131E4F`)이다. 배경·타이포그래피는 기존 흰 바탕과 SUITE/SUIT를 유지한다.

| 키 | 이름 | 형태 |
|---|---|---|
| `side-brick-assembled` | 조립 브릭 고래 | 원본의 길쭉한 3단 몸통에 말랑한 스터드와 둥근 관절 꼬리를 조합 |
| `side-brick-pocket` | 포켓 브릭 고래 | 짧고 도톰한 몸통과 넓은 스터드, 접힌 듯 작은 관절 꼬리 |
| `side-brick-plate` | 플레이트 브릭 고래 | 낮게 쌓은 플레이트 몸통과 길게 열린 꼬리, 차분한 작은 표정 |

차이는 표정 장식이 아니라 몸통의 비율·층의 높이·꼬리 각도로 만든다. 반짝이·볼터치·그라데이션을 추가하지 않는다. 소스가 SVG인 기존 브랜드 시스템이므로 네이티브 벡터를 편집하고 `Logo`의 크기·톤 처리를 재사용한다. 물줄기는 정지된 작은 브릭으로 제한하며 본체를 가리지 않는다.

## 후보 제외와 호환성

알려진 프리셋(렌더링·과거 적용·이력용)과 지금 선택 가능한 프리셋을 분리한다. 선택 제외 8개 키의 SVG·메타데이터는 과거 적용을 읽는 데만 남기고, 관리자 목록과 API의 적용 가능 목록에서는 제외한다. 제외한 프리셋을 현재 적용 중인 경우 현재본은 보여 주되 새로운 적용 대상으로 삼지 않는다. 이력에서는 삭제된 업로드와 선택 제외를 서로 다른 문구로 설명한다.

## 소유권

- 감독자: 이 스펙·`shared/ui/logo/presets/**`·시각 검수·브랜드 문서·볼트·Git/PR.
- Codex worker: `packages/core/src/mascot/**`, API design의 프리셋/서비스/컨트롤러 및 해당 테스트, `views/admin-mascot/**`, 마스코트 E2E와 콘솔 계약 검사.
- 공유 체크아웃과 단일 브랜치에서 진행한다. worker는 Git 변경·서버 재시작·의존성 설치를 하지 않는다.

## 최종 선택과 전역 배포

사용자는 조립형을 최종 선택했고 포켓형·플레이트형을 추가 제외했다. 조립형의 승인된 모습은 그대로 두며 기본값을 `side-brick-assembled`로 바꾼다. 기존 저장된 적용본은 코드 기본값 변경만으로 덮어쓰지 않고 관리자 게시 경로의 사유·리비전 검증을 거쳐 로컬·운영에서 적용한다.

정적 브랜드 에셋은 정본과 생성기의 정합성 검사를 유지해 동기화한다. 별도 Codex가 마크·아이콘 생성기·OG·생성 에셋을 맡고 감독자가 API/core·회귀 검사·문서·Git·배포와 실제 게시를 담당한다. 공유 체크아웃에서 경로를 겹치지 않으며 Git과 서버 제어는 감독자만 수행한다.
