# 조립 브릭 고래 후보 — 2026-10-26

## 사용자 선택

- 원본 브릭 고래의 층진 몸통, 말랑 브릭 고래의 둥근 스터드 세 개, 옆모습 브릭 고래의 관절형 꼬리를 조합한다.
- `first-sketch`·`chubby`·`kawaii-brick`·`three-studs`는 관리자 선택 목록에서 제외한다. 이전 적용값과 감사 이력은 보존한다.
- 관리자 제목의 SUITE 글꼴을 유지한다. 정면 얼굴이나 새 색상 체계로 바꾸지 않는다.

## 완료 기준

1. 조립형·포켓형·플레이트형 세 후보를 새 키로 등록한다. 원본 SVG를 덮어쓰지 않으며 기본값과 사이트의 현재 적용본은 자동으로 바꾸지 않는다.
2. 세 후보 모두 왼쪽 얼굴·오른쪽 관절 꼬리·둥근 스터드 세 개와 가운데 골드를 갖는다. 작은 크기에서도 부드러운 표정과 브릭 실루엣이 읽힌다.
3. 선택에서 제외한 네 그림은 신규 적용과 이력 재선택에서 사용할 수 없다. 기존에 적용되어 있으면 현재 그림·이름과 이력은 정상 표시한다.
4. 밝은 배경·어두운 배경·홈 히어로 및 작은 로고를 실제 Orca 관리자 화면에서 비교한다. 320/375/414/768/1440px에서 넘침·잘린 그림·포커스 문제를 확인한다.
5. API와 공통 코어의 후보 목록은 일치한다. 저장의 사유·권한·리비전 충돌 처리를 유지한다. 웹과 서버 갱신 시점이 다르면 새 후보를 미리 볼 수 있지만 서버가 모르는 키는 적용할 수 없도록 안내한다.
6. 변경을 검증하고 커밋·push·dev PR 병합 및 Obsidian 기록까지 완료한다. 운영 적용·정적 앱 아이콘 변경은 이번 범위가 아니다.
