# 조립 브릭 고래 전역 적용 — 2026-10-26

## 사용자 선택

- 원본의 층진 몸통, 말랑 고래의 둥근 스터드 세 개, 옆모습 고래의 관절형 꼬리를 합친 `side-brick-assembled`를 최종 선택했다.
- 사용자가 이 그림의 전역 적용과 운영 배포, API8090 재시작을 명시 승인했다.
- 선택 제외는 `first-sketch`·`chubby`·`kawaii-brick`·`three-studs`·`blocky`·`fountain`·`side-brick-pocket`·`side-brick-plate` 8개다. 과거 적용과 감사 이력의 렌더링은 보존한다.
- 관리자 제목 SUITE와 본문 SUIT, 현재 조립 고래의 형태·비율·색을 유지한다.

## 완료 기준

1. 조립 고래를 API·코어의 기본값과 정적 브랜드 정본으로 맞춘다. 과거 프리셋은 덮어쓰지 않는다.
2. 알려진 프리셋 17개 중 9개만 새 선택·적용할 수 있다. 제외된 현재본과 이력은 정상 표시하되 재적용을 막는다.
3. 밝고 어두운 배경·홈 히어로·작은 로고·반응형 화면에서 선택한 고래를 확인한다.
4. API와 코어 목록을 일치시킨다. 사유·권한·리비전 충돌 처리를 유지하고 구버전 서버에서 미지원 키 적용을 막는다.
5. 정적 파비콘·OG·앱 아이콘·스플래시를 같은 정본에서 생성한다. 앱 바이너리 배포가 필요한 범위는 웹 배포와 구분한다.
6. 로컬 API를 같은 Orca 터미널에서 재시작하고 조립 고래를 실제 적용한다. 정상적인 dev → main 릴리스와 CD 뒤 운영 적용·공개 화면을 확인한다.
7. 커밋·push·검증·배포 결과와 미검증 범위를 GoLe Obsidian에 남긴다.
