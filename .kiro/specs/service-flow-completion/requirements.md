- PR #244·#245의 원본 커밋과 기능 의도를 보존하며 최신 dev 디자인·인증 개선과 통합한다.
- 가입·인증·로그인 복귀, 탐색·상점·판매, 입찰·제안·대화·거래 완료, 주문·취소·후기, 수집·알림, 부품 요청·커뮤니티의 화면 → API → 저장 상태 → 다음 행동을 점검한다.

- RN 네이티브 탐색과 WebView 역할, 공통 모달·Tailwind·SUIT/SUITE·옆모습 고래 디자인을 유지한다.
- 통합한 최종 상태로 검증하고 커밋·push·dev 병합·팀 볼트 기록까지 마친다.

## 관리자 조치

- 같은 세트 번호의 신규 카탈로그 등록은 409로 거부하고 기존 세트·추천·단종 상태를 보존한다. 동시 등록도 하나만 성공해야 한다. 수정은 기존 수정 API로 수행한다.
- 운영 준비 확인을 취소할 때 공통 모달에서 해당 항목과 단계 하향·결제 차단 가능성을 설명한다. 모달에서 돌아가면 요청을 보내지 않고 사유를 보존한다.
- 취소·분쟁 주문은 관리자 목록의 한국어 상태·선택 필터·직접 링크에서 같은 상태로 연결되어야 한다. 기존 주문 취소 API는 신규 결제 공개가 닫혀도 사용 가능하다.

## 알림 설정 저장

- 서로 다른 탭·기기가 서로 다른 알림 분류를 동시에 바꿔도 각 변경을 보존한다. 전체 설정 교체 대신 변경한 분류만 원자적으로 반영한다. 필수 거래 알림을 끄는 요청은 계속 거부한다.
