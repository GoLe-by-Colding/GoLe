# IP 안전 콘텐츠 (IP-Safe Content) — 요구사항

## 개요

레고 공식 이미지/저작물의 무단 복제·재게시는 저작권/상표 침해 위험이 있다(상업적 중고거래라 특히).
플랫폼은 **텍스트 중심 + 사용자 직접 촬영 사진 + 공식 페이지 외부 링크 + 상표 고지**로 운영한다.

## 요구사항

### R1. 세트 정보는 텍스트로
- **R1.1** 세트명·세트번호·상태·누락부품·설명은 텍스트로 표시한다.
- **R1.2** 플랫폼은 레고 공식 상품 이미지를 가져와 호스팅하지 않는다(카탈로그 세트 이미지는 비워두고 중립 플레이스홀더 표시).

### R2. 공식 페이지는 외부 링크로만
- **R2.1** 세트 표시 시 레고 공식/검색 페이지로 가는 **외부 링크**를 제공한다.
- **R2.2** 링크는 외부 사이트임을 분명히 하고(새 탭, `rel="noopener noreferrer nofollow"`), 공식 사이트를 사칭하지 않는다.

### R3. 이미지는 사용자 직접 촬영만
- **R3.1** 매물 사진은 **판매자가 직접 올린 사진**만 사용한다(공식 이미지 금지를 안내).
- **R3.2** 매물은 **최소 1장**의 사진이 필요하다(도메인 불변식으로 강제 — 기존 `MissingPhotoException`).

### R4. 상표 고지
- **R4.1** 모든 페이지 하단에 고지문구: "LEGO®, 레고®는 LEGO Group의 상표이며, 본 사이트는 LEGO Group의 후원·승인을 받지 않습니다."

## 비범위
- 실제 파일 업로드/스토리지(현재 사진은 URL 입력) — 후속.
- 공식 권리자 이미지 라이선스 확보 — 운영 정책 영역.
