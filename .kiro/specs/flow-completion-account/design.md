# 계정·컬렉션·알림 흐름 완성 설계

## 변경 경로

- `views/profile`: 닉네임 설정 링크에 `/profile` 복귀 경로를 전달한다.
- `views/onboarding`: 조회 오류와 재시도 상태를 분리하고 기존 완료 이동을 유지한다.
- `features/notification-bell`: 계정별 읽음 변경 이벤트와 최신 조회만 반영하는 벨을 제공한다.
  `views/notifications`가 성공 시 이 공개 API를 호출한다. 목록 조회 오류와 읽음 오류는 분리한다.
- `views/notification-settings`: 낙관 표시를 유지하면서 PUT을 순서대로 실행한다. 계정 변경
  이후 이전 계정의 대기 작업은 실행하거나 화면에 반영하지 않는다.
- `app/(main)/app-push-registration.tsx`: 실제 클라이언트 저장 세션을 읽어 등록 여부를
  정하고 등록/해제를 직렬화한다. 성공 후 현재 세션을 다시 확인해 늦은 등록을 정리한다.
  토큰 교체 때 이전 토큰을 해제하고 해제 실패 캐시는 재시도할 수 있게 보존한다. 등록 시도는
  `confirmed: false`로 먼저 기록해 응답을 잃어도 로그아웃 정리를 할 수 있고, 성공만 캐시 재사용한다.
  해제 시작·종료 때 공유 무효화 식별자를 갱신한다. 등록 성공 캐시는 시작 시 읽은 식별자가
  현재 값과 같을 때만 유효하므로 응답 유실과 다른 WebView의 늦은 해제가 재등록을 막지 않는다.
  다른 WebView는 무효화 알림을 받으면 로그인 상태에서 다시 동기화한다. 등록 진행 기록의
  storage 이벤트는 무시해 서로의 등록 시도를 반복해서 유발하지 않는다.
  무효화 식별자는 인증용 값이 아니다. `crypto.randomUUID`가 없는 LAN HTTP 개발
  WebView에서는 시간·난수 조합을 사용하며 저장소 쓰기 실패와 API 미지원은 구분한다.
  해제 요청 뒤 문서가 종료되면 종료 무효화가 실행되지 않을 수 있으므로 앱 진입·focus·
  online 복귀에서는 완료 캐시가 있어도 멱등 POST를 한 번 보장한다. 같은 문서에서
  큐 실행 전에 겹친 재검증 이벤트는 하나의 플래그로 합친다.
  공유 등록 캐시가 다른 토큰이라고 해서 그 토큰을 해제하지 않는다. 토큰 교체 정리는
  이 문서가 실제 등록을 시도한 이전 토큰만 대상으로 삼아, 아직 새 네이티브 토큰을
  전달받지 못한 WebView가 다른 WebView의 최신 토큰을 삭제하지 않게 한다. 로그아웃은
  공유 기록과 이 문서의 시도 기록을 함께 정리하며 해제 실패 기록은 재시도를 위해 보존한다.
- `mobile/features/push-notifications/lib/device-push-token.ts`: Android 채널을 권한 조회·
  요청보다 먼저 생성한다. [Expo SDK 57 알림 문서](https://docs.expo.dev/versions/v57.0.0/sdk/notifications/)의
  권한 요청 순서를 따르며, iOS FCM 등록 및 Expo Go/시뮬레이터 제외 정책은 보존한다.
- `api/account/domain/model/Account`: `verify`는 정지를 먼저 확인한다. `reinstate`는
  정지 상태에서만 전이하며 아직 제거되지 않은 이메일 인증 challenge가 있으면 UNVERIFIED로
  복귀한다. 인증 완료 시 challenge를 제거하는 기존 불변식을 사용하므로 저장 스키마는 바꾸지 않는다.

## 보존 사항

- API/core 계약과 RN 탭·WebView 구조를 바꾸지 않는다.
- 기존 안전한 알림 대상 URL과 인증 복귀 경로 판정, 계정별 조회 경계를 유지한다.
- 공통 UI·폰트·고래 및 운영 잠금은 변경하지 않는다.
- 알림 설정의 서버 전체 문서 저장은 별도 API 소유 범위다. 이 변경은 같은 화면에서
  발생하는 연속 요청을 직렬화한다. 다른 기기 동시 저장의 원자적 갱신은 루트가 담당한다.

## 검증

- 변경 전 재현되는 회귀 시나리오를 추가하고 변경 후 동일 시나리오를 실행한다.
- 계정·알림 E2E에서 세션 복원, 지연 응답, 읽음 실패, 연속 설정, 프로필 복귀를 확인한다.
- 웹 타입·경로 한정 린트/포맷을 실행하고 전체 게이트는 루트와 실행 충돌을 조율한다.
