# 홍보 초안 평가 기록

빈 칸은 미수집이다. 점수 0·비용 0·문제 없음으로 해석하지 않는다.
실제 사용자 정보·비밀·민감한 화면은 이 파일에 붙이지 않는다.
기준: [초안 품질 평가 v1](eval.md).

## 배치

- 배치 ID / 평가일 / 검토자:
- 분류: 릴리스 소식 / 일일 홍보(후속)
- 평가 방식: 실제 모델 / 보관된 실제 초안 / 합성 결과 / 스크립트 드라이런
- 코드 SHA / 모델 ID / 프롬프트 버전 / 평가 기준 버전:
- 입력·사이트 버전 / 최근 게시물 이력 스냅샷:
- 증거 보관 위치 / 접근권한 / 만료일:
- 사전 생성 대상 수 / 사전 건너뛰기 대상 수 / 기대 행동 미확정 수:

## 사례 — 사례·시도마다 복사

- 실제 후보 선정 여부:
- 결과: submitted / intentional_skip / technical_failure / blocked_by_queue / no_candidate / unknown_skip
- 결과 판단 근거 / 오류·한도·건너뛰기 사유:
- 원본 캡션 / 이미지 순서의 증거 위치:
- 주장별 근거: 문구 → 화면·자료 → 일치 / 불일치 / 미확인
