# AI Agent 실행·검토 복구 요구사항

수민의 홍보 초안 기능과 GoLe AI Agent를 Python 실행기 → Spring API → 관리자 웹까지
연결해 보강한다. 기존 문의 분석·영속 작업·사진 변환 계약은 함께 회귀 검증한다.

- 턴 예산을 소진한 홍보 후보는 `deferred`로 남기고 다음 실행에서 실제로 진행한다.
- 마지막 허용 턴에 결정한 도구 실행·초안 제출도 처리한다. 이미 촬영·업로드한 결과를 재사용한다.
- 실행 도중 종료되어 완료 표식이 없는 후보도 재시도 원장에서 복구한다.
- 각 후보 실행 전에 검토 큐를 확인하며, 같은 실행에서 제출한 결과를 다음 후보 이력에 반영한다.
- 반려 초안 재제출은 릴리스 점유를 다시 획득한다. 다른 초안이 점유했다면 충돌로 거절한다.
- 검토 요청 응답이 유실되어 같은 초안을 재제출해도 기존 대기 상태와 제출 시각을 유지한다.
- 잘못된 초안은 미디어 참조를 변경하기 전에 거절한다.
- 관리자 화면에서 필터 변경·늦은 응답·중복 클릭·생성 후 제출 실패 때문에 잘못된 목록이나
  중복 초안이 생기지 않도록 하고, 실패 후 복구할 수 있는 조작과 상태를 표시한다.
- 문의 분석 초안은 사람이 작성 중인 답변을 실수로 덮어쓰지 않도록 한다.

실제 모델 품질 평가는 유료 호출을 포함하므로 이번 로컬 검증과 구분한다. 운영 활성화·실제
외부 발행·배포는 이 변경의 완료 조건이 아니다.
