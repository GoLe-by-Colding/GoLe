# 설계

## Python 실행기

현재 `defer → END` 체크포인트에 `invoke(None)`만 하면 종료 결과가 그대로 반환된다.
완료된 보류 체크포인트의 전사·캡처는 유지하고 실행 턴 예산을 갱신해 다음 노드를 예약한다.
기존 체크포인트의 마지막 미실행 도구도 호환 처리한다. 실패 중인 노드는 기존 재개 규약을 유지한다.
보류는 도구 실행 뒤에 판정해 마지막 턴의 제출을 잃지 않는다. 후보마다 큐와 이력을 조회한다.

## Java 도메인·서비스

재제출할 때 `claimedSourceCommitSha`를 복구하고 직전 검토자·검토 시각·반려 사유를 비운다.
출처는 불변이다. 이미 점유된 릴리스는 서비스 선검사와 기존 unique sparse 인덱스로 거절한다.
`PENDING_REVIEW`에 대한 반복 제출은 저장 없이 기존 결과를 반환한다.
초안 도메인 검증을 미디어 참조 갱신보다 먼저 수행한다.

## 관리자 웹

목록 요청에 세대 번호를 부여해 과거 필터의 응답을 무시한다. 세션 교체 시 화면 상태를 초기화한다.
목록 새로고침과 조치의 오류를 구분한다. 생성에 성공한 초안은 제출 실패와 관계없이 ID를 보존하고
폼을 비워 재생성을 막으며, 해당 초안을 다시 제출할 수 있도록 표시한다. 조치는 동기 ref로 중복
진입을 막고 처리 중 상태를 노출한다. 문의 답변 초안 교체는 기존 작성 내용을 먼저 확인한다.
