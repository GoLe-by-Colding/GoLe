# UI Renewal Requirements

## Goal

기존 GoLe의 파란색·골드 브랜드와 정보 구조는 유지하면서, 효과가 과도하게 겹친 화면을 더 절제되고 일관된 커머스 UI로 정리한다.

## Scope

- 프론트엔드의 시각 표현만 변경한다.
- 라우트, API, 상태 관리, 문구, 데이터 흐름과 기능 동작은 변경하지 않는다.
- 공용 UI 컴포넌트를 우선 수정하고 인증, 헤더, 홈, 푸터, 상품·트렌드 카드에 적용한다.

## Requirements

1. 버튼은 단색 배경을 사용하며 그라디언트, 글로우, 이동·축소 효과를 사용하지 않는다.
2. 입력 요소는 10px, 일반 카드는 14px를 기준으로 하고 `rounded-full`은 상태 배지와 아바타처럼 의미가 있는 경우에만 사용한다.
3. 일반 콘텐츠의 깊이는 테두리와 배경색으로 구분한다. 그림자는 모달 등 실제로 떠 있는 레이어에만 허용한다.
4. 상호작용 전환은 색상, 테두리, 투명도에 한정한다. 자동 재생 티커, 부유·등장 모션, 이미지 확대 효과를 제거한다.
5. 기본 표면은 흰색과 중립색을 사용하고 브랜드 블루와 골드는 핵심 행동과 강조에 제한한다.
6. 브랜드 로고와 외부 로그인 제공자의 고유 색상은 유지하되 넓은 장식 면적으로 사용하지 않는다.
7. 이모지를 아이콘, 순위, 빈 상태 장식으로 사용하지 않는다.
8. 키보드 포커스, 대비, 반응형 레이아웃과 현재의 접근성 역할은 유지한다.

## Acceptance Criteria

- 공용 버튼과 일반 카드에 그라디언트, 글로우, hover 이동·확대가 없다.
- 홈과 인증 화면에 장식용 방사형 그라디언트, 도트 패턴, 자동 애니메이션이 없다.
- 헤더는 불투명한 단색 표면이며 현재 메뉴 표시는 하나의 명확한 표시만 사용한다.
- 데스크톱과 모바일에서 인증·홈 화면의 정보와 주요 행동이 기존과 동일하게 노출된다.
- 타입 검사, 린트와 프로덕션 빌드가 통과한다.
