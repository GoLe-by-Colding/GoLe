- [x] 인증 레이아웃, 인증 탭과 소셜 로그인 버튼을 정리한다.
- [x] 헤더와 푸터의 복합 배경과 장식 요소를 제거한다.
- [x] 홈 히어로, 시세 티커, 섹션 헤더와 CTA를 단순화한다.
- [x] 상품, 게시물과 트렌드 카드의 hover·gradient·emoji 장식을 제거한다.
- [x] 금지 패턴을 검색하고 타입 검사, 린트, 빌드와 반응형 화면을 검증한다.

## Phase 2

- [x] 홈과 인증 화면에 절제된 단색 브랜드 배경을 복원한다.
- [x] 검색, 필터와 탭의 모양과 상태 표현을 통일한다.
- [x] 시세, Q&A, 채팅과 상세 화면의 내부 패널 곡률을 통일한다.
- [x] 2차 변경 후 정적 검사, 빌드와 반응형 화면을 다시 검증한다.

## Phase 3

- [x] 시세 차트의 가격축 잘림과 포인터 좌표 계산을 수정한다.
- [x] 차트의 날짜 눈금, 툴팁 위치와 키보드 탐색을 개선한다.
- [x] 시세 요약 통계와 데이터 테이블의 정보 위계를 정리한다.
- [x] 미디어 로드 실패 시 주요 카드에 일관된 이미지 fallback을 표시한다.
- [x] 차트 색상과 선 굵기가 유지되는지 화면과 빌드로 검증한다.

## Phase 4

- [x] 로컬 개발에서 상대 미디어 URL이 백엔드 원점을 사용하도록 공용 이미지 처리를 보완한다.
- [x] 세트 상세 화면에 다시 들어온 그라디언트·이모지·깨진 이미지 가능성을 제거한다.
- [x] 페이지 제목 크기와 시세 세트 목록의 데스크톱·모바일 밀도를 다듬는다.
- [x] 운영자 콘솔과 조치 오버레이를 공용 곡률·전환·색상 규칙에 맞춘다.
- [x] Phase 4 변경 후 금지 패턴 검색, 정적 검사와 프로덕션 빌드를 검증한다.
