검증 후 레이어별 커밋·push → dev PR 전체 필수 CI → merge commit → 원격 dev 포함 및 main 미변경

`10_개발일지/승찬/2026-10-25/`에 기록한다. 공유 체크아웃을 삭제하지 않는다.
