# Brand Icon Requirements

## 귀여운 고래로 다시 그림 (2026-10-09, 사용자 피드백)

- 사용자: **"고레 캐릭터가 왜 이렇게 무섭게 변했어?"** — 같은 날 확정한 정면 스터드 머리 고래의 스크린샷을 첨부하고
  **"제대로 귀엽게 만들어줘"**라고 했다. 스크린샷은 목표가 아니라 **싫다는 현재 상태**다.
- 무섭게 읽히는 원인 셋: ① 얼굴에 비해 **큰 흰 눈**(눈이 몸에 뚫린 구멍이라 흰 배경에서 흰 눈알이 된다),
  ② 머리 폭의 약 62%를 가로지르는 **과한 U자 웃음**, ③ 머리 뒤로 길게 솟은 **뾰족한 꼬리**.
- 원하는 것: **둥글고 통통한 아기 고래.** 작고 편안한 미소, 작고 부드러운 눈, 볼살이 느껴지는 둥근 몸,
  짧고 둥근 꼬리·지느러미. 기존 입·눈을 단순히 줄이는 데서 그치지 않고 **전체 균형**을 다시 잡는다.
- 유지: 정면 시점, 파란색 몸, 노란 스터드 **1개**, `GoLe` 워드마크, `mark.svg` 정본 + 생성기 체계.
- 금지: 분홍·그라데이션·3D·거대한 흰 눈·이빨.

### 수용 기준

- 16px·32px에서도 얼굴(두 눈)이 식별된다.
- 밝은 배경(파란 고래), 어두운 배경(흰 고래), 브랜드 블루 배경(흰 고래 + 골드)에서 모두 확인한다.
- `pnpm brand:icons`와 `--check`가 통과하고, 생성기의 기존 무알파·세이프존 검사를 통과한다.
- 홈 히어로에서 캐릭터 대비를 확보한다.

### 홈 히어로 (같은 날 root 지시)

- 무거운 짙은 히어로 대신 흰 바탕·충분한 여백·코발트 버튼·노란 한 점의 가볍고 친근한 흰/연한 블루 구성으로 바꾼다.
  모바일 첫 화면에서 CTA와 캐릭터가 함께 보이고, 어색한 크기·빈 공간·과한 그림자가 없다.
- 지표 캡션은 위치어("오른쪽")를 쓰지 않고, 지표가 있을 때만 보인다.
- 골드는 제목과 스터드에만 쓰고, 주 CTA는 brand 블루다.
- CTA는 신규 방문자에게도 항상 참이어야 한다. 서버 컴포넌트를 client로 바꾸거나 계정 조회를 더하지 않는다.

## 카카오 디벨로퍼스 아이콘 추가 (2026-09-23)

- 사용자 요청으로 GoLe 카카오 앱(ID 1563935)에 등록할 전용 아이콘을 만든다.
- 브릭 고래 형태와 로열 블루·흰색·골드 한 칸을 사용하고, 글자 없이 작은 크기에서도 알아보게 한다.
- 카카오 앱 정보 수정 화면에서 확인한 규격은 JPG/GIF/PNG, 권장 128px, 최대 250KB다.
- 생성 원본과 128px 업로드 파일을 함께 보관하고, 앱 이름·회사명은 기존 값을 유지한다.
- 아래 모바일 자산 요구사항은 최초 작업 당시의 기준이다. 카카오용 시안은 기존 웹·모바일 정본을 덮어쓰지 않는다.

## Goal

`ui-renewal` 스펙은 웹에만 적용됐다. 모바일 앱 아이콘과 스플래시는 여전히 **Expo 기본 자산**이고,
웹 `public/`에는 **create-next-app 기본 SVG**가 남아 있다. `brand-identity.md`가 예고한 후속 스펙
(`brand-icon`)을 실제로 수행해, 사용자가 처음 보는 면을 브랜드 마크로 통일한다.

## 현황 (측정값)

- `apps/mobile/assets/expo.icon/`은 레이어가 `expo-symbol 2.svg` + `grid.png`이고 채움색이
  `extended-srgb:0.0,0.478,1.0`(iOS 시스템 블루)다. **iOS 앱 아이콘이 Expo 로고다.**
- `assets/images/icon.png`(1024², 784KB)와 `android-icon-foreground.png`도 같은 Expo 로고이며,
  브랜드 문서가 금지한 **그라데이션 배경**을 쓴다.
- `splash-icon.png`는 228×213 비정방형이다.
- 참조 0건인 템플릿 잔재: 웹 `next.svg` `vercel.svg` `file.svg` `globe.svg` `window.svg` `logo.svg`,
  모바일 `assets/images/tabIcons/`(6개).

## Requirements

1. 모바일 아이콘 일체를 정본 마크(`apps/web/src/app/icon.svg` — 고래 + 골드 브릭 스터드)에서 생성한다.
2. 배경은 **단색** `brand-600 #1D4ED8`을 쓴다. 그라데이션·그리드·글로우를 넣지 않는다.
3. iOS 아이콘은 1024×1024 정방형, 알파 없음, 자체 라운딩 없음(OS가 마스크한다).
4. Android 어댑티브 아이콘은 전경/배경/모노크롬 3종을 규격 세이프존 안에 맞춘다.
5. 자산은 **재생성 가능**해야 한다 — 소스 SVG와 빌드 스크립트를 저장소에 둔다.
6. 참조 0건인 템플릿 자산을 삭제한다. 참조가 있는 자산은 건드리지 않는다.
7. 골드(`accent`)는 스터드 한 곳에만 남긴다(브랜드 규칙: 화면당 1~2곳).

## Acceptance Criteria

- `app.json`이 Expo 기본 `.icon` 번들을 더는 참조하지 않는다.
- 생성된 iOS 아이콘에 알파 채널이 없다.
- `pnpm --filter mobile format:check`·`lint`·`typecheck`가 통과한다.
- 삭제한 파일의 참조가 저장소 전체에서 0건이다.
