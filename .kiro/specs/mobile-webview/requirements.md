# 모바일 웹뷰 요구사항

- 홈·검색·판매·채팅·내 정보 하단 탭은 RN 네이티브로 유지한다.
- 본문은 별도 RN 화면이 아니라 현재 GoLe 모바일 웹을 표시한다.
- 웹의 고래·카드·로그인·업로드 UI를 재사용하고 네이티브 헤더 중복을 제거한다.
- 개발에서는 실행 중인 웹 :3000, 배포 앱은 HTTPS GoLe 원점을 사용한다.
- 신뢰한 원점만 웹뷰에서 탐색하고 외부 링크는 OS 브라우저로 분리한다.
- 뒤로 가기, 실패 재시도, 안전 영역, 기존 미커밋 FCM 변경 보존을 검증한다.
- 이번 변경은 웹 세션을 사용한다. 네이티브 푸시 토큰과 웹 로그인 연결, 실결제·소셜 인증 브리지는 별도 완료 판정을 요구한다.
- 비어 있거나 실패한 공통 미디어에는 카탈로그 시드와 같은 낮은 채도의 브릭 패턴을 표시한다. 기존 실사진은 대체하지 않는다.
