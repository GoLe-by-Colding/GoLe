# 설계

- `features/recent-sets`가 기록 모델·sessionStorage 어댑터·클라이언트 UI를 소유한다.
- 순수 모델이 저장 데이터 검증, 중복 제거, 최대 8개 제한을 담당한다. 번호는 숫자와 선택적 숫자 접미사만 허용하며 이름 길이와 저장 원문 크기를 제한한다.
- `useSyncExternalStore`는 문자열 스냅샷을 구독한다. 서버 스냅샷은 null로 고정하여 SSR/수화 일관성을 유지한다.
- 상세의 검증된 세트 번호·이름을 effect에서 기록한다. 기록 변경은 자체 이벤트로 전달하며 현재 세트가 삭제 직후 재등록되지 않도록 effect 의존성을 번호·이름으로만 둔다.
- `RecentSets`를 검색 하단과 상세 하단에 조합한다. 기존 서버 렌더링·메타데이터·API 호출은 그대로 유지한다.
- 공통 Button·Heading 및 브랜드 토큰을 재사용한다. 링크와 삭제 버튼은 형제 요소로 두어 중첩 인터랙션을 피한다.
- 테스트는 순수 모델 계약과 실제 브라우저의 재방문·삭제·새로고침·저장소 차단을 나눠 검증한다.
