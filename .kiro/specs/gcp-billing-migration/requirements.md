# GCP 결제 이전 요구사항

- 2026-10-24 사용자 요청에 따라 기존 운영 프로젝트의 결제를 coding.ai.dev@gmail.com의 활성 크레딧 계정으로 이전한다.
- 서버·DB·스토리지·고정 IP·도메인·팀원 권한과 기존 운영 버전을 보존한다. 결제 비활성화를 이전 중간 단계로 사용하지 않는다.
- 구 결제 계정은 연결 프로젝트가 0개이고 새 결제 및 운영 정상 상태를 확인한 뒤 닫는다. 이미 발생한 비용의 지연 게시와 새로운 사용료 발생을 구분한다.
- 새 결제 계정의 예산 Pub/Sub와 Discord 알림을 검증한다. 비밀값은 출력하거나 문서에 기록하지 않는다.
- 기존 비용·네트워크 이력을 보존하고, 새 비용 기간은 명시적으로 검토한 정책으로만 적용한다. 기존 정지 가드와 watchdog는 끄지 않는다.
- 반복 무료체험 자격 또는 동일 사양의 90일 무과금 운영을 보장하지 않는다. 실제 잔액·요율·보존 비용을 기준으로 정지선을 계산한다.
