# 수집가의 브릭 선반 — 탐색과 공통 컴포넌트

## 목적

상품 사진·가격·상태를 빠르게 비교하고 원하는 브릭을 찾는 탐색 경험을 만든다. 기존 코발트·브릭 골드와 SUITE·SUIT를 유지하고, 친근한 해요체와 명확한 거래 고지를 함께 쓴다. 사용자 지시: 기능 개발을 계속하면서 톤·컴포넌트·컨셉을 일관되게 정리한다(2026-10-24).

## 확인한 문제

- 자동완성 선택이 검색어만 있는 주소로 이동해 가격·상태·카테고리·정렬을 버린다.
- 최소가가 최대가보다 커도 검색하며 금액 입력 오류를 설명하지 않는다.
- 자동완성은 목록 역할만 있고 키보드 선택·선택 상태·입력 연결이 없다.
- 오류 화면의 같은 주소 링크는 새 조회를 보장하지 않는다.
- 필터 칩은 모바일에서만 보이고 버튼·입력 높이와 초점 표시가 일관되지 않다.
- 상품 카드의 세트 번호 유무로 제목·가격 높이가 달라지고 판매 완료 상태를 표시하지 않는다.

## 수용 기준

1. 검색어 입력·자동완성 선택·필터 제거·전체 해제·뒤로 가기에서 나머지 조건이 보존된다.
2. 가격은 0 이상의 안전한 정수만 받는다. 역전 범위는 이동 없이 오류와 수정할 입력을 안내하며 URL 직접 접근에도 같은 규칙을 적용한다.
3. 자동완성은 방향키·Enter·Escape, 명시적 레이블, combobox/listbox/option 관계를 지원한다. 닫거나 포커스를 옮긴 뒤 늦은 응답으로 다시 열지 않는다.
4. 로딩·빈 결과·조회 실패는 구분한다. 재시도는 현재 조건으로 실제 서버 조회를 다시 수행한다.
5. 상품 카드의 식별 정보→제목→가격→상태 위계를 일정하게 유지하고 예약·판매 완료·부품 누락을 숨기지 않는다.
6. 320·375·414·768px와 데스크톱에서 가로 넘침이 없고 주요 터치 목표는 44px 이상이며 키보드 초점과 오류를 색만으로 전달하지 않는다.
7. 기존 결제·공개 잠금을 보존한다. 사용자 프리뷰 데이터 변경·실결제·외부 메시지 전송 없이 검증한다.
