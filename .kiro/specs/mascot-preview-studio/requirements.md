# 마스코트 비교 스튜디오

## 배경 — 2026-10-26

사용자는 기존 마스코트의 다른 버전을 실제 화면에서 비교하고 GoLe 컨셉에 맞게 더 예쁘게 다듬도록 요청했다. 관리자 화면은 후보 목록 뒤에 미리보기가 있어 좁은 화면에서 결과를 찾기 어렵고, 출처 커밋이 이름보다 과하게 드러난다. 기존 `mascot-assets`의 업로드·적용·감사 계약을 보존한다.

## 요구사항

1. 왼쪽 얼굴·오른쪽 꼬리·브릭 윗면·스터드 세 개와 가운데 골드 포인트를 유지한 새 옆모습 후보를 추가한다. 기존 13종과 기본값·운영자의 선택을 보존한다.
2. 선택한 후보는 상단에서 크게 볼 수 있어야 하며, 작은 헤더 로고·어두운 배경·16/24/48px의 식별성을 같은 화면에서 확인한다.
3. 적용 중인 그림과 미리보기 선택을 명확히 구분한다. 후보 선택만으로 공개 설정을 변경하지 않는다.
4. 저장 중에는 후보 변경과 중복 저장을 막는다. 선택이 바뀌면 적용 확인 체크를 해제한다. 기존 변경 사유·낙관적 잠금·409 충돌 복구를 유지한다.
5. 업로드·삭제 모달·이력 기능을 유지하고, 후보 수를 하드코딩하지 않는다. 출처 정보는 선택을 돕는 설명 다음에 둔다.
6. 기존 SUITE/SUIT·코발트·절제한 골드 토큰과 Tailwind/shared UI를 사용한다. 320/375/414/768px와 넓은 화면에서 가로 넘침·가려진 포커스·눌리지 않는 조작이 없어야 한다.
7. 로컬 브라우저 검증과 fixture E2E를 구분해 기록한다. 이번 작업에서 운영 설정·정적 앱 아이콘·favicon·OG 기본 마크는 자동 교체하지 않는다.
8. 사용자 추가 기준: 급히 자동 생성한 화면처럼 보이지 않도록 장식용 카드·배지·중복 안내를 줄인다. 상태 표시는 선택본/적용본 구분처럼 실제 판단에 필요한 것만 두고, 한글 제목과 조작의 간격·정렬·줄바꿈을 실제 화면에서 검토한다.
