# 롱테일 SEO / 구조화 데이터 — 요구사항

## 개요

브랜드명(`GoLe`)은 유지하면서 검색 유입을 **세트 단위 롱테일 쿼리**로 확보한다.

서비스명에 "레고"를 넣는 방안(`고레고`)은 **채택하지 않는다.** 상표를 언급하는 것(지명적
공정사용)과 상호로 사용하는 것(출처 혼동)은 법적 층위가 다르고, 본 서비스는 상업적
중고거래라 비영리 팬사이트 항변도 쓸 수 없다. `ip-safe-content` R4.1이 강제하는
"LEGO Group의 후원·승인을 받지 않았다"는 고지와도 정면 충돌한다.
대신 **브랜드명은 GoLe로 두고, 검색 키워드는 콘텐츠·메타데이터로 가져간다.**

실제 검색 수요는 브랜드명이 아니라 `"레고 10307 에펠탑 중고"`, `"밀레니엄 팰컨 시세"`처럼
**세트번호·세트명 조합**에 있다. 검색 의도가 명확해 전환율도 브랜드 검색보다 높다.

## 용어

| 용어 | 의미 |
|---|---|
| 롱테일 쿼리 | 세트명/세트번호 + 의도어(중고/시세/가격) 조합 검색어 |
| 세트 상세 | `/sets/{setNumber}` — 세트 1종의 정보·시세·매물을 모은 색인 대상 페이지 |
| 구조화 데이터 | schema.org JSON-LD. 검색결과 리치 스니펫·생성형 검색(GEO) 입력 |

## 요구사항

### R1. 세트 상세 페이지 (롱테일 핵심)

- **R1.1** 시스템은 `/sets/{setNumber}` 경로에 세트별 공개 페이지를 제공해야 한다.
- **R1.2** 페이지는 세트명·세트번호·테마·부품수·출시연도·단종상태를 표시해야 한다.
- **R1.3** 페이지는 해당 세트의 **활성 매물 목록**을 표시해야 한다. 매물이 없으면 빈 상태를 보여준다.
- **R1.4** 페이지는 해당 세트의 **체결가 시세 통계**(최저/평균/최고·거래건수)를 표시해야 한다.
  시세 데이터가 없으면 해당 섹션을 생략한다.
- **R1.5** title은 세트명·세트번호·검색 의도어를 포함해야 한다.
  예: `레고 10307 에펠탑 중고 시세·매물`
- **R1.6** IF 세트번호가 카탈로그에 없으면, 시스템은 404를 반환해야 한다(빈 페이지 색인 방지).
- **R1.7** 페이지는 `ip-safe-content` R2를 지켜 레고 공식 검색 페이지 외부 링크를 제공해야 한다.

### R2. 매물 상세 구조화 데이터

- **R2.1** 매물 상세는 `Product` + `Offer` JSON-LD를 포함해야 한다
  (이름·설명·가격·통화 KRW·재고상태·상태등급).
- **R2.2** `Offer.availability`는 매물 상태에 대응해야 한다
  (ACTIVE→`InStock`, RESERVED→`LimitedAvailability`, SOLD→`SoldOut`).
- **R2.3** 매물에 사진이 있으면 OG 이미지로 첫 사진을 사용해야 한다(절대 URL).
- **R2.4** 매물이 카탈로그 세트에 연결돼 있으면 `BreadcrumbList`로 세트 상세를 상위에 두어야 한다.

### R3. 셀러샵 · 커뮤니티 메타데이터

- **R3.1** 셀러샵(`/shops/{sellerId}`)은 동적 메타데이터를 제공해야 한다. **현재 전무하다.**
- **R3.2** 셀러 후기가 1건 이상이면 `AggregateRating` JSON-LD를 포함해야 한다
  (`review` 스펙의 평점 집계 재사용).
- **R3.3** 커뮤니티 게시글(`/community/{id}`)은 동적 메타데이터와 `Article` JSON-LD를
  제공해야 한다. **현재 전무한데 sitemap에는 포함돼 있다**(색인되나 스니펫이 빈약).

### R4. sitemap · 색인 위생

- **R4.1** sitemap은 세트 상세 URL을 포함해야 한다.
- **R4.2** sitemap은 매물이 있는 셀러샵 URL을 포함해야 한다.
- **R4.3** 개인 전용 화면(`/collection`)은 sitemap에서 제외하고 `noindex`로 표시해야 한다.
  현재 sitemap에 `priority 0.5`로 포함돼 있으나 로그인 사용자 본인 컬렉션이라 색인 가치가 없다.
- **R4.4** 각 공개 페이지는 canonical URL을 선언해야 한다.

### R5. 제약

- **R5.1** 백엔드 변경은 매물 검색에 `setNumber` 필터를 더하는 것으로 **한정**한다.
  기존 도메인 모델·API 계약을 깨지 않는다.
- **R5.2** 모든 구조화 데이터는 실제 데이터에서 파생해야 한다. **평점·재고·가격을 지어내지 않는다**
  (구글 구조화 데이터 정책 위반 시 리치 결과 자격 상실).
- **R5.3** 외부 API·크롤링을 새로 도입하지 않는다.

## 비고 — 다루지 않는 것

- 동적 OG 이미지 생성(`next/og`): 렌더 비용 대비 이익이 불확실해 후속으로 남긴다.
- 다국어(hreflang): 현재 ko-KR 단일 로케일.
