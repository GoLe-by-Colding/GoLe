# CI 계약 검사 개선 요구사항

- 내부 스테이지를 참조하는 정상 멀티스테이지 Dockerfile을 허용하면서 외부 베이스의 SHA-256 고정 의무는 유지한다.
- 미고정 이미지·잘못된 digest·미선언 스테이지를 통과시키지 않는다.
- 실제 브릭 필터 라우트를 상호작용 E2E에 반영하고 한 화면의 assertion 실패가 후속 화면 검사를 생략하지 않게 한다.
- Infra의 부트스트랩·호스트·Secret Sync 검사 단계를 구분해 실패한 계약을 Actions UI에서 식별한다.
- 코드 변경은 별도 fix 브랜치와 dev 대상 PR로 전달한다. PR #130과 운영·시크릿은 변경하지 않고 머지는 사용자가 한다.
