# 휴대폰 사진 정규화 요구사항

- 기존 JPEG/PNG와 지원 가능한 HEIC/HEIF 단일 사진을 서버에서 검증하고 안전한 JPEG/PNG로 정규화한다.
- 확장자나 클라이언트 MIME만 신뢰하지 않고 파일 signature, 크기·픽셀·시간·동시성 제한을 적용한다.
- 방향을 보정하고 EXIF/GPS 등 원본 메타데이터를 제거한다. 지원하지 않는 사진·영상은 원본 저장 없이 거절한다.
- 디코더 부재와 보안 버전 미달은 실패로 처리한다. 모든 휴대폰 형식 지원을 주장하지 않는다.
- 다른 컨텍스트는 NormalizeImageUseCase를 통해 정규화하며 native 디코더나 media 아웃바운드 포트를 직접 참조하지 않는다.
- 근거와 실제 native 변환 범위는 [[verification]]에 기록한다. 이 문서는 기존 구현을 독립 검증한 뒤 현재 계약으로 정리한 역작성 스펙이다.
