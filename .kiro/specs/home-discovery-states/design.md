# 설계

홈 서버 컴포넌트의 병렬 조회를 유지한다. 홈 전용 `loadHomeCollection`이 성공 배열(빈 배열 포함)과
실패 `null`을 구분한다. 조회별 독립 복구이며 오류 원문이나 개인정보를 UI에 출력하지 않는다.
목록 실패는 기존 EmptyState와 LinkButton으로 알린다. 관련 목록 진입은 재시도 성공을 보장한다는
문구가 아니라 다시 확인할 경로로 표시한다. 커뮤니티 구획은 성공·빈 상태·실패 모두 남긴다.
인기 데이터 실패 시 숫자·티커는 표시하지 않고 본문에서 실패 이유를 알린다.
기존 여백·색·제목 위계를 유지한다. 준비 전 홈 소개 문구는 판매 준비 래치와 같은 값을 사용한다.
