# Mascot Assets Requirements

## 배경 (2026-10-10)

- 팀원 요청(채팅): **"다 에셋으로 기능만들어서 어드민에서 바꿀 수 있도록해줘 — 마스코트 계속 바꿀 수 있도록"**.
- 사용자(가원): **"우리가 로고 디자인 뽑았던것들 한번 어드민에서 관리가능하도록 그렇게 놔둬줄래?"**
- 지금 고래 마크는 코드 한 벌(`shared/ui/logo/logo.tsx`)이라 바꾸려면 PR·배포가 필요하다. 그동안 그린 시안은
  `brand-icon` 스펙과 git 이력에만 남아 있고, 화면에서 다시 꺼내 볼 방법이 없다.

## 목표

관리자가 **배포 없이** 사이트에 쓰는 마스코트(고래 마크)를 고르고, 새 그림을 올려 계속 바꿀 수 있다.
지금까지 그린 고래 시안은 모두 "기본 제공 에셋"으로 남아 언제든 다시 고를 수 있다.

## 요구사항

### R1. 기본 제공 에셋 — 지금까지 그린 고래

1. git 이력에 남은 고래 마크 13벌 중 거의 같은 1벌(`e56ad390` ≈ `9f581c70`)을 뺀 **12벌**을 기본 제공 에셋으로 둔다.
2. 각 에셋은 이름·한 줄 설명·출처(커밋·날짜)를 가진다. 원래 그림을 다시 그리지 않고 당시 SVG를 그대로 옮긴다.
3. 기본값은 지금 사이트의 **옆모습 브릭 고래**(`5cc1f3da`)다. 아무것도 게시하지 않았거나 조회에 실패하면 이것을 쓴다.
4. 기본 제공 에셋은 지우거나 이름을 바꿀 수 없다.

### R2. 업로드 에셋 — 새 마스코트

1. 관리자는 이름(1~40자)·설명(0~200자)과 함께 **PNG/JPEG** 이미지를 올려 에셋을 만든다. 투명 배경 PNG를 권장한다.
2. 이미지는 기존 미디어 업로드(`POST /api/v1/media/images`)를 그대로 쓴다 — 서버가 시그니처를 검사하고 메타데이터 없이 재인코딩한다.
   **SVG는 받지 않는다**(스크립트를 품을 수 있어 API 원점에서 제공하면 위험하다).
3. 어두운 배경(푸터)용 이미지를 **선택으로** 함께 올릴 수 있다. 없으면 기본 이미지를 그대로 쓴다.
4. 업로드 에셋은 최대 50개다. 지금 적용 중인 에셋은 지울 수 없고(409), 지우면 이미지 파일도 미디어 수명주기로 폐기된다.

### R3. 적용(게시)

1. 관리자는 에셋 하나를 골라 **변경 사유(1~300자)** 와 "검토했습니다" 확인을 거쳐 사이트에 적용한다.
2. 적용은 덮어쓰기가 아니라 **새 리비전**이다. 리비전에는 에셋 id·이름 스냅숏·조치자·사유·시각이 함께 저장되어
   적용과 그 기록이 따로 성공하지 않는다(디자인 토큰과 같은 방식).
3. 다른 관리자가 먼저 적용했으면(리비전 불일치) 409로 거부하고, 화면은 고른 에셋을 유지한 채 최신 값을 다시 불러오게 한다.
4. 이미 적용 중인 에셋을 다시 적용하지 않는다(400).
5. 이력에서 예전 리비전의 에셋을 다시 적용할 수 있다. 지운 업로드 에셋은 이력에 이름만 남고 다시 적용할 수 없다.
6. 에셋 등록·적용·삭제는 중앙 감사 로그(`/admin/audit`)에도 남긴다. 감사 기록 실패가 조치를 되돌리지 않는다(R8.5).

### R4. 사이트 반영

1. 헤더·푸터·인증 카드·홈 히어로·빈 화면·404/오류 화면의 고래가 적용된 에셋으로 바뀐다. `GoLe` 워드마크는 그대로다.
2. 서버가 첫 HTML에 적용된 에셋을 그려 깜빡임이 없다. 공개 조회는 웹 서버에서 **60초** 캐시되므로 다른 방문자에게는
   최대 1분 뒤 보인다. 적용한 관리자의 탭은 즉시 바뀐다.
3. 조회 실패·알 수 없는 에셋·이미지 로드 실패는 모두 기본 고래로 돌아간다. 마스코트 때문에 화면이 비거나 깨지지 않는다.
4. 분수(spout) 연출은 분수 자리가 정의된 기본 제공 에셋에서만 나온다. 업로드 에셋은 분수 없이 그림만 보인다.
5. 공개 응답(`GET /api/v1/config/mascot`)에는 조치자·사유가 없다.

### R5. 범위 밖 (이번에 바꾸지 않는 것)

- favicon·`apple-icon`·OG 이미지·앱 아이콘·스플래시·알림 아이콘·카카오 앱 아이콘은 **빌드 타임 산출물**이다
  (`scripts/build-brand-icons.mjs`). 관리자 적용으로 바뀌지 않는다 — 바꾸려면 `mark.svg`를 고치고 생성기를 돌린다.
- RN 네이티브 화면은 이번에 연결하지 않는다(앱의 웹뷰 화면은 웹을 따라 바뀐다).

## 수용 기준

- 관리자 콘솔 `/admin/mascot`에서 12개 기본 제공 에셋과 업로드 에셋을 미리 보고(헤더·푸터·히어로 크기), 사유와 확인을 거쳐 적용할 수 있다.
- 적용 후 새로 연 페이지의 헤더 고래가 그 에셋이다(최대 60초). 적용한 탭은 바로 바뀐다.
- 비로그인 401·일반 회원 403으로 모든 관리자 경로가 막힌다. 잘못된 요청은 유스케이스에 닿기 전에 400이다.
- 적용 중 에셋 삭제는 409, 리비전 충돌은 409, 동시 적용은 정확히 한 건만 성공한다(Testcontainers).
- 320·390·768·1440 폭에서 `/admin/mascot`에 가로 넘침이 없다.
