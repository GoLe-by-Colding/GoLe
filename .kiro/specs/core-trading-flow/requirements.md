# 기본 거래 동선과 앱 결제

- 2026-10-21 추가 요청: 브릭 필터처럼 화면별로 다른 제목·여백·로그인 안내·버튼을 공통 디자인 컴포넌트로 통일한다. 홈·검색·시세·커뮤니티·컬렉션·피드·판매·내 정보의 기존 기능을 보존한다.

- 최신 dev를 기준으로 가입·로그인→판매 등록/탐색→매물 상세→채팅·주문→결제 결과→내 거래 동선을 연결한다.
- 세트 페이지에서 시작한 판매는 로그인과 판매자 전화번호 확인 이후에도 세트 번호와 복귀 경로를 보존한다. 일반 온보딩 전화번호 필수 정책과 판매자 번호 확인 진입을 혼동하지 않는다.
- 홈에서 실제 판매 중 매물을 바로 확인하며 모바일 웹의 홈·탐색·판매·채팅·내 정보 진입을 제공한다. RN의 기존 하단 탭과 중복하지 않는다.
- 결제 결과는 서버 주문 상태로 판단한다. 확인 필요·환불·취소·로그인 만료를 성공으로 표시하지 않고 조회/재시도/로그인 복귀를 제공한다.
- 실물 브릭 대금은 PortOne PG 결제로 받는다. Apple/Google 스토어 IAP는 실물 대금에 쓰지 않는다.
- RN은 공식 PortOne SDK의 별도 결제 화면을 사용한다. 신뢰 웹 원점·주문 경로·요청 필드 검증 후에만 열고, 결과는 원래 웹 화면의 서버 원장 검증으로 이어진다. 인증 토큰을 SDK로 전달하지 않는다.
- 기존 고래 옆모습, 로열 블루/브릭 골드 토큰, 공통 모달·Tailwind를 유지한다. 실결제 공개 설정·계약 확인을 가짜로 완료하지 않는다.
# 디자인 보강 — 2026-10-21 사용자 추가 요청

- 제목은 SUITE, 본문은 SUIT의 실제 WOFF2 파일을 자체 제공한다. 웹과 앱 WebView에서 같은 글꼴을 쓰며 라이선스를 함께 보관한다.
- 로고는 왼쪽을 보는 옆모습·브릭 스터드·골드 포인트를 유지하고 작은 크기에서 표정이 읽히도록 다듬는다. 기존 12개 마스코트는 보존하고 새 버전도 관리자에서 선택한다.
- 공통 제목·버튼·로그인 안내·빈 상태의 크기와 간격을 맞추고, 홈에서는 브랜드 소개 다음에 실제 매물을 보여 준다.
- 디자인 기준은 기존 브랜드를 따르는 Hallmark, frontend-design, web-design-guidelines 순서로 적용한다. 기능·키보드·반응형 검증을 함께 수행한다.
