# PR 전용 E2E 요구사항

- R1: dev/main 대상 PR은 기존 E2E 전체 검사를 유지함. 잡 이름과 main 필수 체크를 바꾸지 않음.
- R2: main push에서는 E2E 잡만 조건부로 건너뛰어 배포 대기 시간을 줄임. 다른 CI 잡·배포 검증은 유지함.
- R3: main push의 E2E skipped만 정상 생략으로 인정함. 실패·취소 및 다른 잡의 비성공을 성공 알림으로 표시하지 않음.
- R4: CD는 기존처럼 현재 main SHA의 성공한 push CI를 기다림. 직접 배포·보호 설정 완화는 범위 밖임.
- R5: 규약과 운영 문서를 갱신하고 PR→dev→main 및 실제 CD·운영 헬스를 확인함.
- 범위 밖: E2E 삭제·PR 검사 축소·병렬화·테스트 데이터 분리·디자인 변경.
