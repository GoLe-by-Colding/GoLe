# 공개 표시 이름 (public-display-name)

## 왜 필요한가

온보딩(D9)이 2~12자의 유일한 닉네임을 받지만, 그 이름을 남에게 보여 주는 곳이 하나도 없다.
닉네임은 `GET /me`·온보딩 상태로 **본인에게만** 돌아온다. 그래서 웹은 다른 사람을 가리킬 때
계정 ID 앞 8자를 이름처럼 쓴다 — `276956f9`, `user-col`, `seller-a 님의 샵`.

2026-10-10 눈검수에서 커뮤니티 카드·글 상세·댓글·셀러 샵·팔로잉 피드·채팅 상대·매물 문의가
모두 이렇게 보였다. 운영 계정 ID는 UUID라 실제 화면에서는 `e347d51a` 같은 16진수가 이름 자리에
뜬다. 거래 상대를 알아보는 첫 단서가 이름인데, 지금은 사람을 구분할 수 없다.

## 결정

### D1. 계정 ID 목록으로 닉네임을 한 번에 읽는 공개 조회를 account에 둔다

`GET /api/v1/accounts/public-profiles?ids=a,b,c` → `[{ accountId, nickname }]`.

- 닉네임은 본인이 남에게 보이라고 정한 표시 이름이다(유일성 검사가 그 전제다). 이메일·전화번호·
  상태·권한은 돌려주지 않는다.
- 로그인 없이 읽는다. 커뮤니티·매물·셀러 샵이 비로그인 공개 화면이라 작성자 이름도 같이 보여야 한다.
  계정 ID는 이미 공개 URL(`/shops/{id}`)과 응답에 들어 있으므로 새로 노출되는 식별자는 없다.
- 한 번에 최대 50개. 넘으면 `400 TOO_MANY_ACCOUNT_IDS`. 빈 값·중복은 버린다.
- 요청한 ID마다 한 줄을 돌려준다. 닉네임이 없거나 계정이 없으면(탈퇴로 파기됨) `nickname: null`.
  화면이 "없음"도 캐시해 같은 ID를 다시 묻지 않게 하려는 것이다.

### D2. 각 컨텍스트 응답에 작성자 이름을 넣지 않는다

게시글·매물·댓글·채팅·리뷰 응답마다 `authorNickname`을 붙이면 컨텍스트 열 곳 이상이 account를 알아야
하고, 닉네임을 바꾸면 비정규화된 사본이 남는다. 화면이 ID 묶음으로 한 번 더 묻는 쪽이 결합이 작다.
(`HexagonalArchitectureTest`의 "다른 컨텍스트는 상대 `port.in`만" 규칙과도 맞는다 — 이 조회는
account 안에서 끝난다.)

### D3. 웹은 한 화면의 ID를 모아 한 번에 묻고, 이름이 없으면 지금 표시를 유지한다

- `entities/user`에 `useDisplayNames(ids)`를 둔다. 같은 틱에 요청된 ID를 모아 한 번에 조회하고,
  결과(닉네임 없음 포함)를 탭 단위 메모리에 캐시한다.
- 닉네임이 없으면 **지금처럼 계정 ID 앞 8자**를 쓴다. 표시 규칙을 바꾸지 않아 E2E·스크린샷 기준선이
  닉네임 없는 시드 계정에서 그대로 유지된다.
- 조회가 실패해도 화면은 ID 표시로 그대로 동작한다(이름은 보조 정보다).

## 요구사항

- [x] R1. `GetPublicProfilesUseCase`(account `port.in`)가 ID 목록을 받아 요청 순서대로 `{accountId, nickname}`을 돌려준다. 중복·공백 ID는 버리고, 50개를 넘으면 거부한다.
- [x] R2. `AccountRepositoryPort`가 ID 목록의 닉네임만 투영해서 읽는다(계정 전체·비밀번호 해시를 읽지 않는다).
- [x] R3. `GET /api/v1/accounts/public-profiles`가 로그인 없이 응답하고, 응답에 닉네임 외 개인정보가 없다. 1분 캐시를 허용한다.
- [x] R4. 웹 `useDisplayNames`가 같은 틱의 ID를 한 번에 묻고 결과를 캐시한다.
- [x] R5. 커뮤니티 카드·글 상세·댓글, 셀러 샵 제목·후기 작성자, 셀러 미니 카드, 팔로잉 피드의 사람 목록, 채팅 목록·방 머리글·그룹 발신자, 매물 문의 작성자가 닉네임을 보여 준다. 닉네임이 없으면 지금 표시를 유지한다.

## 범위에서 뺀 것

- 프로필 사진·자기소개 같은 공개 프로필 확장.
- 관리자 콘솔의 계정 표시(관리자는 이메일·ID로 일한다).
- 모바일 네이티브 화면. 웹뷰로 같은 화면을 쓰는 곳은 함께 바뀐다.
