# 설계

- 검색 서버 페이지가 정규화한 필터를 `ListingFilterBar`의 key로 전달하여 URL 변경 시 입력 상태를 새로 만든다. 필터 토글에 펼침 상태와 제어 대상을 명시한다.
- `PriceExplorer`는 선택 상태를 공유하는 모바일 select와 데스크톱 목록을 breakpoint로 전환한다. 시세 제목과 근거 배지를 줄바꿈하고 금액 요약은 휴대폰에서 한 줄씩 읽는다.
- `CommunityPage`의 제목·설명과 액션을 모바일에서는 위아래로 배치하고 기존 `/parts`를 연결한다. 푸터에도 같은 진입점을 둔다.
- 홈/푸터의 여백만 반응형 유틸리티로 조정한다. 옆모습 고래·공통 브릭 이미지 대체·브랜드 색은 유지한다.
- `AdminBar` 내부 줄바꿈과 최대 폭, safe-area 하단 여백을 적용한다. 권한 판정·조치 API는 그대로 사용한다.
- 로컬 main의 기존 병합 커밋은 보존한다. origin/dev를 기준으로 작업하고 검증 후 PR로 dev에 병합한다.
