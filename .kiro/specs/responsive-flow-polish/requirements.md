# 반응형 동선 정리 — 요구사항

- R1. 검색 필터 칩을 제거하거나 뒤로/앞으로 이동하면 입력값·필터 수·결과가 현재 URL과 일치한다. 제거한 조건이 다음 검색에서 되살아나지 않는다.
- R2. 휴대폰·태블릿 시세 화면은 긴 세트 목록 대신 선택 상자를 제공하여 현재 세트·가격·차트를 먼저 볼 수 있다. 데스크톱 목록과 같은 선택/정렬·URL 동작을 유지한다.
- R3. 커뮤니티와 푸터에서 기존 부품 요청 게시판으로 바로 이동할 수 있다. 글쓰기와 부품 요청은 좁은 화면에서도 잘리지 않는다.
- R4. 홈 섹션·푸터 여백은 작은 화면에서 줄이고 넓은 화면의 간격은 유지한다. 시세 헤더·금액은 좁은 폭에서 겹치거나 잘리지 않는다.
- R5. 관리자 부유 도구는 작은 화면에서도 조치와 접기 버튼이 모두 보이고 안전 영역을 존중한다. 변경은 Tailwind와 기존 공통 UI로 구현한다.
- R6. 실제 로컬 API와 Orca 브라우저로 동선을 검증한다. 정책·외부 연동 때문에 비활성인 판매/결제/소셜 로그인을 임의로 활성화하지 않는다.
