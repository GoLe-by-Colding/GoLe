# FCM 토큰 계약 수정

- iOS APNs 토큰을 FCM HTTP v1으로 등록하지 않는다. Firebase Messaging 등록 토큰을 사용한다.
- Android의 기존 FCM 등록을 보존한다. Expo Go·웹·권한 거절·미구성 네이티브 모듈은 등록하지 않고 앱 사용을 유지한다.
- 토큰이나 자격증명을 로그에 출력하지 않는다.
- 푸시와 인앱 알림의 서버 매물 경로를 RN 상세 경로로 변환하고 외부/인코딩 우회 경로를 차단한다. 미지원 내부 화면은 알림 목록으로 보낸다.
- 실제 푸시 수신은 네이티브 개발 빌드·Firebase/APNs 구성·서버 발송을 통해 별도로 검증한다. 정적 테스트로 대체하지 않는다.
