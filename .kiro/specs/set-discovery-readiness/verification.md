## 재현과 수정

- 운영 회귀: 준비 false인데 판매 링크2개 노출로1건 실패, 로그인 경로1건 통과. 운영에는 쓰지 않음.
- 세트 판매 링크를 준비 상태와 연결하고 닫힌 경우 이유·운영 문의를 제공함.
- 입찰 등록은 buy-bids D10에 따라 유지함. 판매 수락이 준비 중임과 기간 내 거래 미개방 시 만료 가능성을 안내함.
- 매물 조회 실패(null)와 정상 빈 배열을 분리하고 건수·빈 문구·다시 불러오기를 일치시킴.
- 검색 바로가기의 거래 가능 약속을 세트 정보·시세·구매 희망 가격 탐색 안내로 바꿈.
