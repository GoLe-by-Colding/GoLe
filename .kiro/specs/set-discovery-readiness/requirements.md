# 세트 탐색에서 거래 준비 상태를 일치시킴

- 운영 375px 세트 상세에서 판매 준비 미완료인데 판매 링크 2개와 즉시 거래 안내가 노출됨을 확인함.
- 준비 상태가 false이거나 조회에 실패하면 세트 판매 링크를 노출하지 않고 준비 이유와 문의 경로를 제공한다.
- 구매 입찰 등록은 buy-bids D10에 따라 유지한다. 수요 등록과 실제 판매 수락 가능 여부를 명확히 구분한다.
- 매물 조회 실패는 0건·빈 매물·판매 중 0건으로 표시하지 않는다. 재시도 행동을 제공한다.
- 검색 바로가기는 준비 여부와 무관하게 사실인 세트 정보·시세·입찰 현황 탐색을 안내한다.
- 기존 판매자 신원확인·결제·서버 권한·입찰 생성 계약은 변경하지 않는다.
