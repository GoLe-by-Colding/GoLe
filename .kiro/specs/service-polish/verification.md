## 환경 해석

- API는 개인 `.env` 기준 8090, 웹 3000, Metro 8081이며 모두 Orca 포그라운드 터미널에 유지한다.
- 로컬 데이터와 공개 설정은 운영 사용자·실제 거래·운영 기능 공개 상태의 증거가 아니다.
- Orca의 숨겨진 브라우저 패널은 rAF가 멈춰 React 스트리밍 경계가 스켈레톤에 남을 수 있다.
  실제 UI에서 해당 탭을 선택한 뒤 검수하며, DOM 강제 실행을 통과 근거로 쓰지 않는다.
- 모바일 브라우저 스크린샷의 하단 합성 중복은 네이티브 화면/DOM과 대조했다. 제품의 중복 헤더로 단정하지 않는다.
