# 운영 웹 이미지 요구사항

- 루트 pnpm 매니페스트가 참조하는 보안·호환 패치가 설치 단계와 최종 이미지에 모두 존재해야 한다.
- 일반 Next.js 빌드뿐 아니라 운영 Dockerfile의 실제 이미지 빌드를 CI 필수 Frontend 잡에서 검증한다.
- 최종 이미지는 운영과 같은 CPU·메모리 제한과 일반 사용자로 시작해 `/icon.svg`를 제공해야 한다.
- 일반 사용자 시작 시 패키지 매니저를 외부 레지스트리에서 새로 내려받지 않는다.
- 이미지 검증은 외부 API·운영 데이터에 접속하거나 호스트 개발 포트를 사용하지 않는다.
- 로컬 에이전트 설정과 하위 경로의 브라우저 테스트 결과·보고서는 Docker 빌드 컨텍스트에서 제외한다.

근거: CD 40106250554가 `/src/patches/zod@4.6.7.patch` ENOENT로 실패했다. 기존 운영 버전은 정상이며 비용 가드 전환은 호환 이미지 배포 성공까지 보류한다.
